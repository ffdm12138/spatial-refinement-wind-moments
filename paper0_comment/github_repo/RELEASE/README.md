# Fixed Comment diagnostic data

from the private comment-revision-20261001 Release using install_diagnostics.py.
The existing PT products are held separately in the private raw-data-multicase-v1
Release. See the root README and definitions/PT_RELEASE_MANIFEST.json for access,
filenames, checksums and optional source replay. No PT tensor is committed here.
