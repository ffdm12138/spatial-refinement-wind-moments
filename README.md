# Paper0 and Paper0 Comment post-processing code

This private repository snapshot contains the post-processing source used by
the Paper0 Article and its separate three-state Comment. The two code trees are
indexed in [paper0/README.md](paper0/README.md) and
[paper0_comment/README.md](paper0_comment/README.md).

The current branch contains source code, small configuration files, dependency
lists and documentation. It contains no raw tensors, derived archives, fitted
objects, manuscript files or figure outputs. The previously published
`raw-data-multicase-v1` GitHub Release retains the A/B/C `.pt` tensors; this
code update does not replace or alter those Release assets.

The repository remains private. During peer review, request repository access
and any additional derived inputs from the corresponding author. A GitHub URL
to this repository does not imply public access. The code snapshot alone does
not reproduce historical WRF simulations or the full Article prediction
streams.
